# ros.db.atlas 0.1.0

- Extract schema metadata and descriptions from the IOTC ROS 4.0.0 database into editable CSVs.
- Preview and apply edited descriptions in PostgreSQL, and save the SQL for reuse.
- Generate offline HTML reports and dependency graphs for ALL, LL, PS, PL, and GN.
- Link reference tables to the official IOTC code lists.
